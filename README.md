## 📖 О проекте

**Башҡорт теле** — веб-платформа и Telegram-бот для ежедневной языковой практики и коллективного накопления башкирских переводов. Пользователь получает фрагмент на башкирском языке и предложенный перевод, затем подтверждает его или предлагает исправление. Система сохраняет ответы, привязывает их к источникам и помогает формировать проверенную базу переводов.

Проект ориентирован на школьников, студентов, преподавателей и всех, кто изучает башкирский язык.

## ✨ Возможности

- **Ежедневные задания:** проверка и исправление предложенных переводов.
- **Несколько языковых пар:** башкирский → русский (`ba-ru`), казахский (`ba-kk`), алтайский (`ba-alt`), арабский (`ba-ar`), якутский (`ba-sah`) и китайский (`ba-zh`). Доступность материалов зависит от наполнения базы.
- **Словарь:** поиск по башкирскому тексту и переводу, отображение отдельных слов или фраз, указание происхождения записи.
- **Озвучивание:** синтез башкирской речи отдельным сервисом и озвучивание переводов средствами браузера при наличии соответствующего голоса.
- **Повторение:** просмотр ранее выполненных заданий.
- **Прогресс и мотивация:** баллы, уровни, достижения, история ответов и рейтинги пользователей, классов и школ.
- **Учебные возможности:** классы, регистрация учеников преподавателем и отчёты о работе класса.
- **Проверка переводов:** очередь ответов для проверки и согласование подтверждённых переводов.
- **Доступ к данным:** REST API, Swagger и выгрузка переводов в CSV.
- **Telegram-бот:** ежедневные задания и выбор языковой пары прямо в мессенджере.

> **Как начисляются баллы в этом исходном коде:** новый ответ сохраняется со статусом `pending` и **не приносит баллы до проверки**. После одобрения начисляется **10 баллов за подтверждение** или **15 баллов за исправление**; отклонённый ответ приносит 0 баллов. Автоматической смысловой оценки произвольного перевода здесь нет.

## 🚀 Быстрый запуск

### Требования

- Docker Desktop с поддержкой Docker Compose;
- доступ в интернет для скачивания Docker-образов, датасетов и модели синтеза речи;
- для Telegram-бота — токен от [@BotFather](https://t.me/BotFather).

### 1. Скачайте проект

```powershell
git clone https://github.com/danilmukhyanov-prog/bashkort-tele.git
cd bashkort-tele
```

### 2. Настройте переменные окружения

```powershell
Copy-Item .env.example .env
```

Откройте `.env` и задайте секреты. Пример обязательных настроек:

```dotenv
POSTGRES_PASSWORD=CHANGE_TO_STRONG_DATABASE_PASSWORD
DATABASE_URL=postgresql+psycopg://school:CHANGE_TO_STRONG_DATABASE_PASSWORD@db:5432/school
SECRET_KEY=CHANGE_TO_A_LONG_RANDOM_SECRET_OF_AT_LEAST_32_CHARACTERS
ADMIN_EMAIL=admin@example.org
ADMIN_PASSWORD=CHANGE_TO_STRONG_ADMIN_PASSWORD
BOT_TOKEN=
PUBLIC_URL=http://localhost:8000
```

**Важно:** `POSTGRES_PASSWORD` должен совпадать с паролем внутри `DATABASE_URL`. В приложенном `.env.example` первой переменной нет — добавьте её вручную. Если база уже существует, изменение пароля в `.env` само по себе не меняет пароль существующего пользователя PostgreSQL.

Дополнительно поддерживаются `YANDEX_API_KEY`, `YANDEX_FOLDER_ID`, `YANDEX_TRANSLATE_ENDPOINT` для интеграции с Yandex Cloud Translate.

Никогда не публикуйте `.env`, токен Telegram или реальные пароли в GitHub.

### 3. Запустите сайт и базу данных

```powershell
docker compose up -d --build
```

После запуска доступны:

- **Веб-сайт:** http://localhost:8000
- **Документация API:** http://localhost:8000/docs
- **Проверка состояния API:** http://localhost:8000/health

Сервис API создаёт необходимые таблицы при запуске. Учётная запись администратора создаётся по значениям `ADMIN_EMAIL` и `ADMIN_PASSWORD` при соответствующих условиях в приложении.

### 4. Загрузите данные для заданий

Без предварительного импорта база может не содержать заданий для выбранной языковой пары.

```powershell
docker compose exec api python -m scripts.import_hf --dataset phrasebooks --limit 1000
```

Для дополнительных текстовых источников предусмотрены режимы `books` и `periodicals`:

```powershell
docker compose exec api python -m scripts.import_hf --dataset books --limit 300
docker compose exec api python -m scripts.import_hf --dataset periodicals --limit 300
```

Источник разговорников: [bashkorttele/trilingual-parallel-phrasebooks-bgpu](https://huggingface.co/datasets/bashkorttele/trilingual-parallel-phrasebooks-bgpu). Проверяйте условия лицензирования каждого набора данных до распространения его содержимого.

## 🤖 Telegram-бот

1. Создайте бота через [@BotFather](https://t.me/BotFather) командой `/newbot`.
2. Запишите выданный токен в переменную `BOT_TOKEN` файла `.env`.
3. Запустите бота:

```powershell
docker compose --profile telegram up -d --build
```

Основные команды: `/start`, `/daily`, `/language`, `/profile`, `/cancel`. Задания и результаты бота хранятся в общей с веб-сайтом PostgreSQL.

## 🔊 Словарь и озвучка

Для синтеза **башкирского текста** запустите дополнительный сервис:

```powershell
docker compose --profile voice up -d --build
```

Для запуска всех компонентов вместе:

```powershell
docker compose --profile telegram --profile voice up -d --build
```

В словаре предусмотрены кнопки воспроизведения башкирского слова и его перевода.

- Башкирская речь генерируется моделью [`facebook/mms-tts-bak`](https://huggingface.co/facebook/mms-tts-bak). Первая генерация может потребовать скачивания модели и значительных ресурсов компьютера.
- Озвучивание переводов использует голоса браузера/операционной системы. Если подходящий голос отсутствует, озвучка языка может быть недоступна.
- Сервис TTS кеширует сгенерированные аудиоданные в Docker-томе `ttsdata`.

**Лицензирование:** модель Meta MMS-TTS Bashkir доступна на условиях **CC BY-NC 4.0**. Для коммерческого использования необходимо отдельно проверить права и выбрать подходящее решение.

Если озвучка не работает:

```powershell
docker compose --profile voice ps
docker compose --profile voice logs --tail=100 tts
docker compose logs --tail=100 api
```

## 🧑‍🏫 Учётные записи и доступ

В базе предусмотрены роли `student`, `teacher` и `admin`.

- **Ученик:** выполняет задания и отслеживает собственный прогресс.
- **Учитель:** работает с учебными данными, классами и проверкой ответов в рамках реализованных методов API.
- **Администратор:** имеет доступ к административным операциям.

> Текущая модель классов использует связи `school_id` и `class_id`. Она **не реализует полноценную модель индивидуального владения несколькими классами каждым преподавателем**. Перед использованием с реальными школьными данными следует провести аудит разграничения доступа и персональных данных.

## 🌐 API

Интерактивная документация: **`http://localhost:8000/docs`**.

Примеры маршрутов:

| Метод | Маршрут | Назначение |
| --- | --- | --- |
| `POST` | `/v1/auth/register` | Регистрация |
| `POST` | `/v1/auth/login` | Вход |
| `GET` | `/v1/me` | Профиль |
| `GET` | `/v1/daily` | Задание дня |
| `POST` | `/v1/answers` | Отправка ответа |
| `GET` | `/v1/dictionary` | Словарь |
| `GET` | `/v1/dictionary/{fragment_id}/audio` | Башкирская озвучка |
| `GET` | `/v1/practice/review` | Повторение |
| `GET` | `/v1/leaderboard` | Рейтинг |
| `GET` | `/v1/translations` | Собранные переводы |
| `GET` | `/v1/translations/export.csv` | CSV-экспорт |
| `GET` | `/v1/teacher/class-report` | Отчёт по классу |
| `GET` | `/v1/moderation/answers` | Очередь проверки ответов |
| `POST` | `/v1/moderation/answers/{answer_id}/decision` | Решение по ответу |

Часть методов требует авторизации и соответствующих прав.

## 🔐 Безопасность и хранение данных

- Не загружайте `.env`, токены, реальные пароли, резервные копии БД и персональные данные в публичный репозиторий.
- Не используйте демонстрационные пароли на публичном сервере.
- Для размещения в интернете настройте HTTPS, резервное копирование, ограничения доступа и мониторинг.
- PostgreSQL хранит пользователей, задания, ответы, фрагменты, переводы и рейтинговые данные в томе `pgdata`.
- Не выполняйте `docker compose down -v`, если хотите сохранить данные: команда удаляет тома проекта.

## 📌 Ограничения

- Качество переводов зависит от исходных корпусов и ручной проверки.
- Отправленные задания ожидают проверки: полноценная автоматическая семантическая оценка переводов в данном коде отсутствует.
- Для некоторых языковых пар в базе может не быть данных.
- Голосовой синтез башкирского языка может требовать заметного времени и ресурсов; точность произношения нужно оценивать отдельно.
- Для продуктивного использования в образовательных учреждениях необходима дополнительная проверка защиты персональных данных и доступа учителей к классам.
